# Creator Economy Hack NYC

Static event website inspired by the official event flyer. Run `npm run build` then `npm run dev` for http://127.0.0.1:3001. Deploy with `npx vercel --prod`.

Includes responsive layouts, interactive camera shutter, four keyboard-accessible challenge tabs, FAQs, and timezone-correct calendar download. Registration uses the official Luma event; no registration data is stored by this site. Project ideas are illustrative, not live AI tools. Google Fonts have system fallbacks. No runtime services, API keys or paid dependencies are needed.

Event source: https://luma.com/creator-economy-hack-nyc (checked October 28, 2026). November 22, 2026, 9 AM–6 PM Eastern, New York. Venue requires registration. Flyer is the official event artwork. Event details can change; Luma is authoritative.
